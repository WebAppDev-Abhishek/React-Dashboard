# DataStore Dashboard

A modern, high-performance analytics dashboard built with React and Tailwind CSS. This project features interactive data visualizations, user management tools, and a responsive layout designed for data-driven decision making.

![Dashboard Preview](https://picsum.photos/seed/dashboard/1200/600)

## 🚀 Features

- **Interactive Charts**: Real-time data visualization using Recharts, including line charts for user trends and donut charts for activity distribution.
- **Metric Overview**: Quick-glance metric cards with trend indicators and custom gradient styling.
- **User Management**: A comprehensive data table with search, filtering, and pagination for managing user records.
- **Performance Monitoring**: Dedicated gauges for conversion rates, bounce rates, and restricted user tracking.
- **Responsive Design**: Fully optimized for all screen sizes, from mobile devices to ultra-wide monitors.
- **Smooth Animations**: Elegant entrance and state transitions powered by Motion.

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Charts**: [Recharts](https://recharts.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Motion](https://motion.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/WebAppDev-Abhishek/datastore-dashboard.git
   cd datastore-dashboard
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## 📝 Environment Variables

The project uses the following environment variables (configured in `.env.example`):

- `GEMINI_API_KEY`: Required for AI-powered insights (if enabled).
- `APP_URL`: The base URL of the application.
